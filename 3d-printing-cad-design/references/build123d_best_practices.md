# build123d 工业级参数化建模最佳实践 (build123d Best Practices)

## 1. 消除布尔相交与重叠融化 (Avoiding Solid Fusion)
当设计包含交叉结构（如十字碳管十字交错）时，绝不能依赖模糊的布尔交集：
- **明确几何分界平面**：必须指定截面切平面（如 `Box(mode=Mode.SUBTRACT)`）严格裁剪上下接合面。
- **强制厚度壁厚**：正交通道之间必须保留明确的实体壁厚（例如 `H_divider >= 3.0mm`）。

## 2. 保证特征突出的视觉与受力对比 (Prominent Features)
- 若夹具需要抱紧圆管，不要将圆孔埋进扁平长方体中。
- 应让圆柱壳体的半径 $R_{cyl}$ 远高于耳片固定法兰厚度 $H_{ear}$：
  ```python
  R_tube = 6.0    # 管半径
  R_cyl = 9.5     # 外圆柱壳半径 (高 9.5mm)
  H_ear = 4.5     # 螺栓耳片厚度
  # 结果：半圆柱体高出耳片整整 5.0mm，形成极其清晰的圆柱包裹筒身！
  ```

## 3. 避免细小孤立碎面与非水密网格
- 对接的实体拉伸面应完全覆盖被切物体边界（余量 $+0.1 \sim +0.2\text{mm}$），防止产生零厚度共面（Zero-thickness coplanar）导致的几何拓扑错误。
- 倒角（`fillet`）应在所有大特征与打孔操作完成后统一进行；对复杂曲面交线，优先使用斜角（`chamfer`）以避免 B-Rep 几何求解失败。
