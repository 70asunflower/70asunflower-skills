## 新建项目必须先走 project-init（硬规则）

任何「建新项目 / 初始化项目 / 接管已有项目」的动作，**第一件事是调用 `project-init` 技能**，不要先建目录、先写文件。它负责立底线：git 管理、`AGENTS.md` 唯一规范来源、三层留痕（`memory/MEMORY.md` + `memory/<日期>.md` + 每个正式文件的同名 `.log.md`，条目必须带 `模型：`）、命名约束。

`project-init` 跑完**立即用 `project-review` 跑一次基线审查**并记下起始分数，此后阶段性复查。

项目内的具体规范以该项目 `AGENTS.md` 为准；本规则只管「什么时候必须触发这两个技能」。
