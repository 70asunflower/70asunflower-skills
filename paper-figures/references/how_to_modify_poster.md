# 学术海报与易拉宝后续修改与交付指南（协作者指引）

这份指引是为需要继续修改、调整内容或协助送印海报的合作者/朋友准备的。

---

## 一、双轨产物与格式关系

在本项目中，海报生成体系采用了**双轨交付**（Dual-Track Delivery）：

| 文件名称 | 格式与规格 | 主要用途 | 修改方式 |
|---|---|---|---|
| **`academic_poster_30x80cm.pptx`** | **PowerPoint 原生矢量幻灯片**<br>(30 cm × 80 cm，严格 1:2 缩放) | **日常编辑、文本微调、重排版式、替换插图** | **直接在 Office / WPS 中双击编辑**，所有文字框、卡片、图元均为独立原生形状 |
| **`academic_poster_60x160cm.pdf`** | **印刷级矢量 PDF**<br>(60.6 cm × 160.6 cm，含 3mm 出血与 CMYK 300 DPI) | **直供印刷厂出片制作 60cm × 160cm 易拉宝** | 由 Python 脚本基于 ReportLab 生成，或从调整完毕的 PPTX 导出 |
| **`fig_*.png`** | 高分辨率机制图 (300 DPI) | 嵌入海报的结构机制图表 | 在 `scripts/template_figure_diagram.py` 中重绘或用画图软件修改替换 |

## 二、如何继续修改海报？（两种推荐路径）

### 路径 A：在 PowerPoint (PPTX) 中纯手工可视化修改（最直观、推荐大多数人）
1. 使用电脑上的 **Microsoft PowerPoint** 或 **WPS** 打开 `academic_poster_30x80cm.pptx`；
2. **修改文字**：直接双击任意文本框（如作者名、单位、正文要点），按需修改措辞；
3. **调整排版**：所有深蓝标题横幅、浅灰背景卡片、圆角胶囊标签均可自由移动、拉伸或更改颜色；
4. **替换插图**：如果想更新某个机制图，在 PPT 里选中旧图片按 `Delete` 删除，将新图直接拖拽放入并对齐居中；
5. **保存与导出**：
   - 保存为 `.pptx` 文件；
   - 点击【文件】 $\to$ 【另存为】 $\to$ 选择【PDF】格式即可快速导出矢量 PDF。

> [!TIP]
> **送印特别提示（给喷绘店/印刷厂）**：
> 告诉印刷店师傅：**“这份 PPTX 是按 1:2 等比制作的（30cm × 80cm），请按 200% 等比喷绘至 60cm × 160cm 成品易拉宝。”**
> 或者直接将导出的 PDF 文件发送给印刷店，所有文字与线条均为矢量，200% 放大印刷没有任何锯齿。

---

### 路径 B：通过 Python 脚本自动化重新编译（适合程序员与 AI Agent）
如果希望全自动维护“代码即设计”，修改脚本源码即可重新生成：
1. **修改 PPTX 脚本**：打开 `build_poster_pptx.py`（或 `template_poster_pptx.py`），调整文字、字号或卡片高度；
2. **运行生成**：
   ```bash
   python scripts/template_poster_pptx.py
   ```
3. **修改 PDF 脚本**：若要同步更新印刷级 PDF，打开 `build_academic_poster.py` 并运行：
   ```bash
   python scripts/template_poster_pdf.py
   ```
4. **运行双轨一致性检验**：
   ```bash
   python scripts/verify_poster_diff.py academic_poster_60x160cm.pdf academic_poster_30x80cm.pptx
   ```
   脚本会自动切出 4 个垂直视区（顶部标题区、Sec1-2 理论区、Sec3 机理三联图区、Footer 结论区）拼接对比，排查是否出现孤悬标点、文字截断或版式错位。

## 三、修改时的五大硬性“防翻车”红线

1. **【正文字号底线】**：
   - 在 1:2 PPTX 中，正文主体字绝对**不能小于 15 pt**（对应 1:1 印刷尺寸下不小于 30 pt）。小于 15 pt 在展会现场参会者站立阅读时会严重看不清。
2. **【底部机械卷轴留白】**：
   - 易拉宝底部需卷入金属底座内，底座边缘会遮挡约 3–5 cm。
   - **画布最底部 2.7–3.1 cm（对应 1:1 下 5.5–6.2 cm）必须留白**，严禁放置正文、参考文献或基金字样！
3. **【标点避头尾】**：
   - 检查每一行开头，**绝对不能出现单个逗号 `，`、句号 `。`、分号 `；` 孤悬在行首**。若出现，请将上一行稍微调宽 2mm，或者在逗号后按 `Enter` 主动换行。
4. **【插图标注水平文字】**：
   - 图表内所有文字标注必须保持 **0 度绝对水平**，严禁随箭头斜着摆放。
5. **【主标题双行平衡】**：
   - 长标题建议分两行居中排布，两行字数尽量接近，形成稳重庄严的视觉块。
