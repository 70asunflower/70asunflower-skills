# 周报前后对照（五个场景）

每个例子都遵守同一条规则：**改后版本不得出现材料里没有的事实**。加粗的是材料里原本就有、但容易被写丢的细节。

---

## 一、小改动多的一周（研发）

**材料**

```
样式问题改了一堆，都是小的
首页列表加载慢，加了索引，从 1.8s 到 400ms
顺手把 lint 报的 warning 清了
周三请假半天
```

**差**

> 本周持续优化系统性能与代码质量，完成多项界面细节调整与性能提升工作，代码规范度显著改善。

**好**

> 本周
> - 首页列表加了索引，**1.8s 降到 400ms**，这是这周唯一有数的事。
> - 样式问题清了一批，都是小的，没单独记。
> - lint 的 warning 顺手清完了。
>
> 其他
> - 周三请假半天。

**点评**：一堆小改动本来就该一句话带过，硬凑成「多项工作」反而显得虚。有数的只有一条，就让它占篇幅；「没单独记」比编三个小标题诚实。

---

## 二、推进不动的一周（跨部门）

**材料**

```
数据权限的事找了三个人，都说不是自己管
对方接口文档是旧的，字段对不上，来回问了两次
自己的部分写完了，等他们联调
```

**差**

> 本周积极推进跨部门协作，与相关团队就数据权限问题进行了充分沟通，接口对接工作有序开展中。

**好**

> 在做
> - 数据权限这块**找了三个人**，安全说是平台管、平台说是业务管，还没找到对的人。
> - 对方的接口文档是旧的，**字段对不上**，问了两次还没拿到新版。
> - 我这边代码写完了，等他们联调。
>
> 下周
> - 权限的事准备直接找他们组长，再这么问下去这周就废了。

**点评**：推进不动的周报，价值全在「卡在谁身上、卡了几次」。写成「有序开展中」，读的人既不知道进度也不知道该帮什么。「准备找组长」是下一步，写出来才是有效求助。

---

## 三、没做出东西的一周（排查 / 救火 / 学习）

**材料**

```
线上那个偶发的 500 查了三天，最后是连接池配置，不是代码
帮运营导了两次数据
看了两天 k8s 的文档，还没上手
```

**差**

> 本周深入排查线上问题，同时积极支持业务部门工作，并利用业余时间持续学习新技术，个人能力得到进一步提升。

**好**

> 本周
> - 线上那个偶发 500 查了三天，最后是**连接池配置**的问题，不是代码。改完到现在没再出现。
> - 帮运营导了两次数据。
>
> 在做
> - 在看 k8s 的文档，还没上手，暂时落不了地。
>
> 备注
> - 这周主要时间在查那个 500，别的没怎么动。

**点评**：查三天的 bug 是硬产出，别因为「没写新功能」就心虚。「还没上手」比「能力得到提升」有用得多——前者是真的，后者是安慰。

## 四、科研 / 学生

**材料**

```
复现了 baseline，比论文低 1.2 个点，怀疑是数据划分不一样
跑了 6 组消融，3 组有提升
组会讲了一次
论文 Introduction 改到第二稿
```

**差**

> 本周围绕课题开展了大量实验工作，完成了 baseline 复现与多组消融实验，实验结果符合预期，并积极参与学术交流，论文写作稳步推进。

**好**

> 本周
> - baseline 复现出来了，但**比论文低 1.2 个点**，怀疑是数据划分不一致，还没验证。
> - 6 组消融跑完，**3 组有提升**，另外 3 组没动。
> - Introduction 改到第二稿。
>
> 其他
> - 组会讲了一次。
>
> 下周
> - 把数据划分对上，确认那 1.2 个点是真差还是切分问题。

**点评**：「比论文低 1.2 个点」是这周最有价值的信息，写成「符合预期」等于把发现藏起来。一半实验没效果就写一半没效果，科研周报里没人信「全部有提升」。

## 五、带人 / 管理

**材料**

```
新人上手了，能独立提 MR 了，review 还是得盯
跟 A 聊了一次，他想换组
季度目标对了一遍，有两个要延期
自己的方案写了一半
```

**差**

> 本周持续关注团队建设与成员成长，新人已顺利融入团队并独立承担开发任务；同时完成季度目标复盘，识别风险并制定应对措施。

**好**

> 本周
> - 新人能独立提 MR 了，review 还是得盯，两个小问题都是边界没考虑。
> - 季度目标对了一遍，**两个要延期**，一个是依赖外部、一个是人力不够。
> - 自己的方案写了一半。
>
> 需要关注
> - 跟 A 聊了一次，他想换组，原因没说透，下周再聊。
>
> 下周
> - 两个延期的目标给出新的时间点。

**点评**：管理周报里，「谁想走」「哪个目标要延期」才是上面要看的。写成「识别风险并制定应对措施」，风险本身没了，措施也成了空话。

## 通用反例速查

| 别写 | 改成 |
|---|---|
| 深入对齐 / 充分沟通 | 跟谁、对了几次、定了什么 |
| 稳步推进 / 有序开展 | 做到哪一步、卡在哪 |
| 有效提升 / 显著改善 | 提升多少（有数）或直接说做了什么（没数） |
| 持续关注 / 积极支持 | 具体做了什么，做了几次 |
| 为 X 奠定基础 | 删掉，或者写清 X 什么时候开始 |
| 下周将继续努力 | 删掉，写具体要做的两三件事 |
